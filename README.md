# NikType

کیبورد هوشمند فارسی و انگلیسی برای اندروید — طراحی‌شده برای تجربه تایپ روان، سریع و به‌ویژه **مناسب انگشت‌های درشت**.

> NikType یک کیبورد واقعی اندرویدی است که در تنظیمات سیستم ثبت می‌شود و در همه برنامه‌ها قابل استفاده است. کاملاً آفلاین، بدون تبلیغ و بدون ارسال هیچ داده‌ای.

## ویژگی‌ها

### موتور تایپ هوشمند
- تشخیص کلید بر اساس مختصات لمس با مدل احتمالاتی گاوسی
- اصلاح اشتباهات ناشی از برخورد با کلیدهای مجاور (رفع ابهام در سطح واژه)
- پیشنهاد کلمات حین تایپ و پیش‌بینی کلمه بعدی (بی‌گرام)
- اصلاح خودکار محافظه‌کارانه (از انتخاب اشتباه جلوگیری می‌شود؛ واژه‌های درست هرگز تغییر نمی‌کنند؛ با Backspace قابل بازگردانی است)
- یادگیری تدریجی الگوی تایپ کاربر — کاملاً روی دستگاه
- پشتیبانی از واژه‌های محاوره‌ای فارسی
- نیم‌فاصله هوشمند (چیپ پیشنهادی، کلید اختصاصی و نگه‌داشتن کلید فاصله)
- تایپ کشیدنی (Swipe Typing) با رمزگشای مسیر
- پیشنهاد ایموجی بر اساس واژه قبلی

### سیستم مخصوص انگشت‌های درشت
- سه پروفایل آماده: **Small Fingers / Normal Fingers / Large Fingers**
- در حالت Large Fingers: کلیدهای بزرگ‌تر، فاصله بیشتر و حساسیت بالاتر روی کلیدهای مجاور
- تنظیم مستقل ارتفاع کلید، فاصله، عرض و ارتفاع کل کیبورد
- کالیبراسیون تطبیقی لمس (موتور انحراف لمس هر کاربر را یاد می‌گیرد و جبران می‌کند)
- تطبیق با سرعت تایپ (در تایپ سریع تلورانس تشخیص بیشتر می‌شود)

### امکانات
- تایپ فارسی و انگلیسی با جابه‌جایی سریع
- اعداد فارسی و انگلیسی، علائم نگارشی فارسی (، ؟ ؛)
- نگه‌داشتن کلید برای حروف جایگزین (ا → آ أ إ ...)
- تایپ صوتی (با تشخیص گفتار خود دستگاه)
- میانبرهای متنی (تایپ عبارت کوتاه → متن کامل)
- حذف سریع کلمه با کشیدن روی Backspace
- چسباندن از کلیپ‌بورد با نگه‌داشتن کلید فاصله (انگلیسی)

### شخصی‌سازی
- شش تم: Dark Neon، Purple Galaxy، Ocean Blue، Minimal Black، Pure White، Glass UI
- تغییر ارتفاع کیبورد، اندازه کلیدها، فاصله، گردی گوشه‌ها، اندازه فونت، شفافیت
- تغییر رنگ کلیدها و پس‌زمینه
- تنظیم شدت لرزش و صدای کلیدها
- انتخاب انیمیشن (بدون / استاندارد / شاد و فنری)
- انتخاب چیدمان فارسی (استاندارد / الفبایی)

## نصب

### دریافت APK
1. به صفحه [Actions](../../actions) مخزن بروید و آخرین بیلد سبز را باز کنید.
2. از بخش Artifacts فایل `NikType-debug-apk` را دانلود و باز کنید.
3. (در نسخه‌های تگ‌دار) APKها در بخش [Releases](../../releases) هم قرار می‌گیرند.

### فعال‌سازی
1. فایل APK را نصب کنید (اجازه نصب از منابع ناشناس را بدهید).
2. برنامه را باز کنید؛ راه‌اندازی مرحله‌ای شما را هدایت می‌کند:
   - معرفی NikType → انتخاب زبان‌ها → انتخاب اندازه انگشت → تنظیم اندازه کیبورد → فعال‌سازی در تنظیمات سیستم → انتخاب به‌عنوان کیبورد پیش‌فرض.
3. تایپ را شروع کنید.

## حریم خصوصی
- **بدون دسترسی اینترنت** — برنامه اصلاً مجوز INTERNET ندارد؛ هیچ داده‌ای نمی‌تواند خارج شود.
- یادگیری کلمات و کالیبراسیون لمس فقط در حافظه داخلی دستگاه ذخیره می‌شود.
- در فیلدهای رمز عبور: هیچ پیشنهاد، اصلاح یا ذخیره‌ای انجام نمی‌شود.
- بدون تبلیغ، بدون ردیاب، بدون دسترسی غیرضروری (فقط VIBRATE و RECORD_AUDIO برای تایپ صوتی).

جزئیات بیشتر: [docs/PRIVACY.md](docs/PRIVACY.md)

## معماری

```
NikType/
├── app/                  ← لایه اپلیکیشن اندروید (UI، سرویس IME، تنظیمات)
│   ├── ime/              ← سرویس InputMethodService + میزبان Compose
│   ├── keyboard/         ← کنترلر ورودی، رندر Canvas، نوار پیشنهاد
│   ├── settings/         ← صفحات تنظیمات و شخصی‌سازی
│   ├── onboarding/       ← راه‌اندازی شش‌مرحله‌ای
│   ├── themes/           ← کاتالوگ تم‌ها
│   ├── voice/            ← تایپ صوتی
│   └── data/             ← DataStore و ذخیره‌سازی یادگیری
├── keyboard-engine/      ← موتور کیبورد (Kotlin خالص، بدون وابستگی اندروید)
│   ├── geometry/         ← چیدمان‌های فارسی/انگلیسی و هندسه کلیدها
│   └── touch/            ← موتور تشخیص لمس احتمالاتی + کالیبراسیون
├── prediction-engine/    ← موتور پیش‌بینی (Kotlin خالص)
│   ├── dictionary/       ← درخت پیشوندی واژگان
│   ├── correct/          ← اصلاح خودکار محافظه‌کارانه
│   ├── suggest/          ← پیشنهاد و پیش‌بینی کلمه بعدی
│   ├── context/          ← مدل بی‌گرام و مدل کاربر
│   ├── swipe/            ← رمزگشای تایپ کشیدنی
│   ├── text/             ← ابزار متن فارسی و نرمال‌سازی
│   └── data/             ← داده‌های واژگانی محلی
└── docs/                 ← مستندات معماری و حریم خصوصی
```

نمودار جریان داده و شرح الگوریتم‌ها: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## ساخت از سورس

```bash
./gradlew :app:assembleDebug          # APK دیباگ
./gradlew :app:assembleRelease        # APK ریلز (امضانشده)
./gradlew :keyboard-engine:test :prediction-engine:test   # تست‌های موتورها
```

نیازمندی‌ها: JDK 17 و Android SDK 34.

## CI/CD
هر push به `main` از طریق GitHub Actions اجرا می‌شود:
1. اجرای تست‌های واحد موتورها
2. ساخت `app-debug.apk` و `app-release-unsigned.apk`
3. بارگذاری APKها به‌عنوان Artifact (و در تگ‌های `v*` به‌عنوان Release)

امضای ریلز: کلید امضا هرگز وارد مخزن نمی‌شود؛ برای امضا محلی از `scripts/sign-apk.sh` استفاده کنید.
